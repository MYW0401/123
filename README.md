# MBTI 性格速测

一个零依赖的单文件 MBTI 性格测评网页小工具。

## 在线使用

部署到 GitHub Pages 后，直接打开 Pages 链接即可使用（见下方链接）。

## 功能

- 20 道原创中文单选题，覆盖 E/I、S/N、T/F、J/P 四个维度
- 作答进度显示，支持上一题、下一题、重新测试
- 结果页展示 MBTI 四字母类型、四维倾向百分比、每个字母的含义与类型特点说明
- 响应式布局，电脑和手机都易于阅读
- 零外部依赖、零网络请求、不保存任何数据

## 本地使用

直接下载 `index.html`，双击用浏览器打开即可，无需安装任何东西。

## 声明

本测评仅供娱乐和自我了解，不构成心理诊断或专业建议。
